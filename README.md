## Draggable Tabs Componen

This is a demo website built as a test task featuring a tab component with the following functionality: Tabs can be rearranged via drag-and-drop, and their order persists after page reload. Tabs can be pinned in place. Tabs that don't fit into the visible area of the container are shown in a dropdown menu with scrolling. When the screen width changes, tabs that no longer fit are moved to the dropdown and vice versa — they return to the main area. Each tab is assigned a unique URL, and switching between tabs triggers navigation to the corresponding URL.
